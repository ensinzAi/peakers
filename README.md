# PEAKERS

Сайт бренда аквасоков PEAKERS. Одна статическая страница без сборки: ни Node, ни npm, ни зависимостей. Всё, что нужно для работы, лежит в двух объектах.

```
index.html    страница целиком: разметка, стили, скрипты
img/          110 фотографий товаров в WebP
```

Шрифты (Unbounded, Golos Text, JetBrains Mono) подключаются с Google Fonts.

## Как опубликовать на GitHub Pages

1. Создай репозиторий и залей в него `index.html`, папку `img` и этот файл.
2. Settings → Pages → Source: `Deploy from a branch`.
3. Branch: `main`, папка `/ (root)`. Save.
4. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Если подключаешь свой домен, добавь его в Settings → Pages → Custom domain и заведи у регистратора CNAME на `<логин>.github.io`.

## Что нужно заменить перед запуском

Всё перечисленное это заглушки. Пока они на месте, сайт нельзя показывать покупателям.

| Что | Где искать в `index.html` |
|---|---|
| Цены (сейчас 2500 у всех) | `price:2500` в массиве `P` |
| Телефон, email, Telegram | блок `<footer>`, раздел «Связаться» |
| Ссылки на соцсети | `<a href="#" class="soc"` в футере |
| ИП и ИНН | `.ft-bot`, строка с копирайтом |
| Отзывы | массив `REV`, 12 записей |
| Рейтинг 4,9 и 10 000+ отзывов | блок `.hero-trust` |
| Проценты в преимуществах (30, 65, 90) | массив `TECH` |
| Ссылка на OZON | объект `LINKS`, ключ `oz` |

**Отзывы важнее всего.** Сейчас там 12 правдоподобных, но выдуманных текстов. Публикация выдуманных отзывов это нарушение закона о рекламе и о защите прав потребителей. Замени их настоящими с карточек WB и OZON до того, как пустишь на сайт трафик.

## Настройки в начале скрипта

```js
var MODE = 'site';   // 'site' или 'mp'
var PAY_URL = '';    // ссылка на оплату Робокассы
var LINKS = { wb: '...', oz: '...' };
```

`MODE` решает, какая кнопка на карточке главная: «В корзину» или «Купить на Wildberries». То же самое переключается тумблером в футере, он виден только владельцу и на продажи не влияет.

`PAY_URL` пустой, поэтому кнопка оплаты пока показывает подсказку. Вставь ссылку Робокассы, и она начнёт работать.

## Как добавить или заменить фото

Фото лежат в `img` и подключаются в объектах `PH` и `USE`:

```js
'AK-2025-2|grey': {
  main: ['ak-2025-2-grey-01.webp', ... ],   // слайд 1: коллаж
  use : ['ak-2025-2-grey-use-01.webp', ... ] // слайды применения
}
```

В `main` первый файл это общий вид, дальше проекции. Если положить в `main` один файл, он покажется целым слайдом, так сделано у AK-2026-1 с готовым коллажем.

Формат: WebP, ширина 1100 px для обычных кадров и до 1500 px для первого. Качество 84. Исходники по 2-8 МБ сжимаются до 100-300 КБ, разница на глаз не видна.

Если файл не найдётся, вместо него подставится нарисованный силуэт аквасока, страница не сломается.

## Модели

| Артикул | Название на сайте | Цвета |
|---|---|---|
| AK-2025-1 | Аквасоки на шнурках | бежевый, чёрный |
| AK-2025-2 | Аквасоки на резинке | чёрный, бежевый, персиковый, серый |
| AK-2025-3 | Аквасоки на шнурках | сиреневый |
| AK-2025-4 | Аквасоки на шнурках | жёлтый |
| AK-2026-1 | Аквасоки на липучке | серый |
| AK-2026-2 | Аквасоки на шнурках | коричневый |

Названия задаются в объекте `NAME`: там перечислены только резинка и липучка, всё остальное по умолчанию идёт как «на шнурках».

## Что работает на странице

Корзина с пересчётом суммы, выбор цвета и размера на карточке, карусель слайдов со свайпом на телефоне, калькулятор размера по длине стопы, аккордеон с вопросами, форма заказа с проверкой полей и маской телефона, подписка на рассылку, переключатель приоритета трафика.

Бэкенда нет: заявка не уходит на почту, а показывает подтверждение с номером. Чтобы заявки реально приходили, нужен обработчик формы. Самое простое это Formspree или Telegram-бот через Cloudflare Worker.

## Права на фото

Репозиторий на GitHub по умолчанию публичный, вместе с ним публичными станут все 110 фотографий. Товарные снимки и так лежат на маркетплейсах, так что риска обычно нет. Но если в папке окажется что-то не предназначенное для чужих глаз, делай репозиторий приватным: GitHub Pages работает и с приватных репозиториев на платных тарифах.
